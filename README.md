# Analyse de transactions bancaires

## 🎯 Objectif du projet
Ce projet a pour objectif d’analyser un jeu de données de transactions bancaires
afin d’identifier des tendances, des comportements clients et des indicateurs clés
pouvant soutenir la prise de décision.

## 📊 Données
- Jeu de données utilisé dans un contexte académique
- Données financières et variables descriptives des transactions

## 🧪 Méthodologie
- Nettoyage et préparation des données
- Analyse exploratoire (EDA)
- Création de visualisations claires et interprétables
- Analyse et interprétation des résultats

## 📈 Résultats
- Identification de tendances importantes dans les transactions
- Mise en évidence de comportements récurrents
- Visualisations facilitant la compréhension des données

## 🛠️ Outils et technologies
- Python
- Pandas
- Matplotlib / Seaborn
- Jupyter Notebook

## 📌 Contexte académique
Projet réalisé dans le cadre de la formation en science des données appliquées.
